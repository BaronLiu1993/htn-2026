# Guideline A — 2025 Commercial Property

This package preserves the supplied 2025 carrier appetite. The JSON file is the deterministic decision contract. The linked `property-cope` investigation profile guides evidence collection but does not add acceptance thresholds.

Boundary values that the source does not classify remain unresolved. This includes buildings from exactly 1990, an exactly 50% acceptable-construction share, and exactly $100,000 in applicable five-year losses.
