# Insurance Glossary

## Core insurance concepts

**Insurance:** A financial product that provides protection against specific risks (accidents, illness, or property damage). Customers pay a premium, and the insurer promises to cover certain losses.

**Underwriting:** The process insurers use to evaluate the risk of insuring someone or something. Underwriters decide whether to accept or reject applications and how much to charge.

**Carrier:** Another name for an insurance company (for example, Allstate or AIG).

**Policy:** The formal agreement (contract) between the insured (customer) and the insurance company. It outlines what is covered, how much coverage is provided, and under what conditions.

**Premium:** The amount a customer pays (monthly, quarterly, or annually) for insurance coverage.

**Submission:** A request for insurance sent by a broker or agent to an insurer, including details about what is being insured (a building, vehicle, or person).

## RiskOps / Federato context

**RiskOps:** Short for “Risk Operations.” At Federato, this refers to the tools and workflows that help underwriters make smarter, faster decisions using data and AI.

**Appetite:** What kinds of risks an insurer wants to take on. For example, a carrier might have appetite for commercial auto insurance in Texas, but not for homes in wildfire-prone areas.

**In-appetite:** A submission that matches what the insurer is looking for. It is high-priority for underwriters.

**Out-of-appetite:** A submission that does not align with the insurer’s current interests or guidelines.

## Data and technology terms

**Dashboard:** A web interface that shows key information at a glance, such as a list of top submissions for the day, charts of premium amounts, or risk scores.

**API (Application Programming Interface):** A way for software systems to talk to each other. This project uses an API to get submission data.

**SQL (Structured Query Language):** A programming language used to access and manipulate databases, for example to filter submissions with `premium > $100,000`.

**JSON (JavaScript Object Notation):** A lightweight format used to exchange data between systems. Data retrieved from the API will come as JSON.

**Filtering:** Selecting only the data you want from a larger dataset, for example only submissions from California.
